Graph Theory & Adjacency List

เครือข่ายโรงภาพยนตร์ (Cinema Graph Network)

การแทนข้อมูลความสัมพันธ์ระหว่างสาขาโรงหนัง (Vertex = สาขา, Edge = ระยะทาง/ค่าจัดส่งตั๋ว)

Vertices (|V|): 6 จุด (A, B, C, D, E, F)
Edges (|E|): 8 เส้นทาง (Weighted Graph)

แผนผังเครือข่ายกราฟแบบ Interactive

ลากจุดเพื่อเปลี่ยนตำแหน่งได้

คำอธิบายทฤษฎีกราฟในระบบ

Vertex (V): แทน "สาขาโรงภาพยนตร์" ทั้งหมด 6 สาขาในระบบ

Edge (E): แทน "เส้นทางเชื่อมต่อ/ระยะเวลาเดินทาง (นาที)" ระหว่างสาขา

Weighted Graph: มีค่าน้ำหนักบน Edge แสดงระยะเวลาเพื่อใช้คำนวณการจัดส่งฟิล์ม/ตั๋วระหว่างสาขา

Tree Hierarchy & Decision Path

โครงสร้างต้นไม้ระบบตัวเลือกภาพยนตร์ (Movie Decision Tree)

แสดงลำดับชั้นข้อมูล Root → Category (Parent) → Movie (Child) → Showtime (Leaf)

Tree Height: 4 ระดับ (Levels 0-3)
Root Node: "CineGraph Application"

แผนผัง Tree Hierarchy Visualizer

ซูมเข้า/ออก เพื่อดูโครงสร้างทุก Node ได้

โหมดการท่องต้นไม้ (Tree Traversal Animations)

คลิกปุ่ม Traversal ด้านบนเพื่อดูการสแกนข้อมูลแบบต่าง ๆ บน Tree

องค์ประกอบของ Tree ในระบบ

Root Node (ระดับ 0)

จุดเริ่มต้นระบบ "CineGraph Main App"

Parent Nodes (ระดับ 1 & 2)

หมวดหมู่ภาพยนตร์ (Sci-Fi, Action, Animation) และชื่อภาพยนตร์แต่ละเรื่อง

Leaf Nodes (ระดับ 3)

รอบเวลาฉายหนัง (13:00, 16:30, 19:30, 21:00) ซึ่งไม่มี Child Node ต่อไปอีก

Root(App) → Action → Cyberpunk 2099 → 19:30 PM (Leaf)
